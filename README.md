##DevOps
- 데브옵스 수업 실습 레포지토리
- 실습 관련 파일과 주차별 학습 내용 정리

####목표
- 리눅스 명령어와 셸 스크립트 반복 작업 자동화를 통한 학습
- Git 브랜치와 PR로 팀 단위 협업 학습
- 팀 단위로 전체 파이프라인 설계 및 구축 문서화

####기대하는 학습 효과
- 개발부터 배포, 운영까지의 전체적인 소프트웨어 흐름 및 생명주기 이해
- 리눅스, 깃, 도커 등을 직접 사용하여 실무 역량 기르기
- 배포 오류, 네트워크 문제, 서비스 장애 등을 분석하고 해결하는 트러블 슈팅 능력 향상
- Git 브랜치와 PR을 활용한 협업 및 프로젝트 수행을 통해 현업 수준의 협업 프로세스와 버전 관리 역량 경험
