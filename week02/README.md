## 서버(Server)
- 서버는 하드웨어, 스프트웨어 둘 다 해당

### 서버 운영 방법
1. 베어메탈
    * PC 한 대에 OS 설치 후 여러 소프트웨어 운영
    * 하나의 OS에서 모든 프로그램을 관리하기 쉬움
    * 가상화에 따른 오버헤드가 적음
    * 하드웨어를 세밀하게 제어가능
    * 구조가 단순하여 관리 쉬움
2. 하이퍼바이저(가상화)
    * 하나의 물리 서버를 여러 개의 가상 컴퓨터(VM)로 나눠주는 소프트웨어
    * 각 VM은 독립적인 게스트OS와 커널을 가짐
    * CPU, 메모리, 저장장치 등의 물리 자원을 가상화하여 VM에게 할당
    * VM이 실제 컴퓨터처럼 동작할 수 있도록 가상 하드웨어 환경 제공
3. 컨테이너(가상화)
    * 하나의 컴퓨터 안에서 여러 애플리케이션을 서로 격리된 환경에서 실행
    * 별도의 게스트OS와 커널 없이, 호스트OS의 커널 기능으로 격리된 공간 생성 가능
    * 모든 컨테이너가 호스트OS의 커널을 공유
    * 네임스페이스와 제어 그룹을 사용하여 커널을 공유하면서도 프로세스와 자원을 격리 및 관리

- 네임스페이스(namespace): 컨테이너가 무엇을 볼 수 있는지 격리
- 제어 그룹(cgroups): 컨테이너가 얼마나 많은 자원을 사용할 수 있는지 제한 및 관리
